# The animals' 3D models

Each species has one `web/models/<species id>.glb`, generated by a Blender
script in `scene/` (Blender 2.93, run headless) and never hand-edited, so a
change is a change to the script. Open Fly's fly was made the same way
(`Open-Fly/scene/fly_at_computer.py`), and its fly-building code is the starting
point for ours.

    /Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup \
        --python scene/<script>.py -- --out web/models --previews data/raw/previews

## What every model must be

- **Units are metres at stage scale**, not life scale: an animal sits on a desk
  in front of an 80 cm-wide monitor. Target lengths, nose to tail tip:
  fly 0.30, larva 0.30, worm 0.26, sea squirt larva 0.24, zebrafish larva 0.36,
  mouse 0.30 body + 0.25 tail.
- **Axes as the page uses them:** +Y up, the animal faces **−Z** (towards its
  screen), origin at the centre of where it rests, so y = 0 is the surface it
  sits on (desk, agar, or for the fish the middle of the water).
- **Smooth, not faceted:** subdivision surface (or skin modifier + subsurf)
  applied before export; smooth shading; no visible primitives.
- **Materials:** Principled BSDF only, which glTF carries as
  metallic-roughness. Colour detail as vertex colours or small baked textures
  (≤ 512²). Translucency via alpha (worm cuticle, fish body, fly wings).
- **Size:** ≤ 2 MB per `.glb`, ≤ 60k triangles.
- **Looks like the animal** to someone who knows it: judged from rendered
  previews against the anatomy, not against the old placeholder.

## The animation contract

The page animates these by name; nothing else is assumed. Bones are in one
armature named `rig`, exported with skinning; three.js drives their rotations.

| species id | named for the page |
|---|---|
| `drosophila_female`, `drosophila_male` | nodes `head`, `leg_front_L`, `leg_front_R` (tap on orders), `wing_L`, `wing_R` |
| `drosophila_larva` | bones `spine_0` (head) … `spine_11` (tail): peristalsis |
| `c_elegans_herm`, `c_elegans_male` | bones `spine_0` (nose) … `spine_23` (tail): travelling wave in the XZ plane |
| `ciona_larva` | bones `tail_0` … `tail_11`: swimming beat |
| `zebrafish_larva` | bones `spine_0` (behind the head) … `spine_11`; nodes `eye_L`, `eye_R` |
| `mouse_v1` | nodes `head`, `nose`, `whiskers_L`, `whiskers_R`, `ear_L`, `ear_R`; bones `tail_0` … `tail_11` |

Rest pose: straight (worm, larva, sea squirt, fish), sitting (mouse), standing
(flies). A bone's local rotation about its own Y (up) axis bends the body
sideways; about X bends it up/down.
